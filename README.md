# Orange Card v16 — 補色が消えたあとを記録する道具

七田式オレンジカードの練習を記録するツールです。
**v15までとは、測っているものが違います。**

## v15 から何が変わったか

v15までは「残像をどれだけ長く保てたか」を主な指標にしていました。
これは間違いでした。長く保つほど褒める作りだったので、**力むように仕向けていました。**

視覚野が静かなほど心に浮かぶ映像は鮮明になる、という実験結果があります。
力むと視覚野は静かになりません。つまり
**補色にしがみつく行為と、鮮明な映像を見る行為は、両立しません。**

v16 は、補色が消えたあとに何が起きるかを記録します。

| | v15まで | v16 |
|---|---|---|
| 主な指標 | 残像の持続時間・効率比・自己ベスト | **正色が出た割合・力まずにできた割合** |
| 残像の秒数 | グラフの主役 | 記録はするが、褒めない |
| 効率比・PBバッジ | あり | **廃止** |
| パターンA〜F判定 | あり | **廃止**（根拠がないため） |
| 練習の流れ | 凝視 → 計測 | 環境チェック → 色を見る → 足場 → **脱力** → 傍観 |
| 確かめる仕組み | なし | **カードなしの回・色を変える回**を混ぜる |

削除した機能の理由と、残した機能の根拠は、アプリの「分析」タブに全部書いてあります。

## 練習の流れ

1. **環境チェック（5秒）** … 目を閉じて、まぶたの裏が何色に見えるか答えます
2. **色を見る（15秒）** … まばたき自由。色をよく見ておきます（あとで使う「インク」）
3. **足場をつくる（15秒）** … ソフトフォーカスで中心をぼんやり。まばたきも自由です
4. **脱力（8秒）** … 目を閉じ、息を長く吐いて、眼の奥の力を手放します
5. **傍観** … 画面は真っ黒。**何か変わったら画面のどこでも触ります**。長押しで終了
6. **記録** … 触った点に、あとから意味をつけます

合計2分ほど。**1回に長くやるより、短いものを1日に数回**のほうが向いています。

### 傍観フェーズの操作

目を閉じたまま操作するので、入力は2つだけです。

- **軽く触る** … 「何か変わった」。何回でも、0回でも構いません
- **長押し（約1秒）** … 終了

「いま何が起きたか」を目を閉じたまま判断する必要はありません。
開眼後の記録画面で、押した時刻を並べて見せるので、そこで意味をつけてください。

## 暗い部屋か、アイマスクを使ってください

**まぶたは赤〜オレンジの光をよく通します。**青い光はあまり通しません。

明るい部屋で目を閉じると、視野はもともと赤橙色をしています。
つまり **カードを見なくてもオレンジ色が見えます。**
補色（青系）は透過が悪いので暗く沈み、「補色が消えて正色が残った」ように見えてしまいます。

環境チェックで「赤橙っぽい」と答えると、その回は「明るい部屋」として記録され、
分析タブで暗い部屋の記録と分けて表示されます。

## 確かめるための回について

10回に1回ほど、**カードを出さない回**と、**オレンジ以外の色を出す回**が混ざります。
記録画面では、何を出したかを表示しません（表示すると、答えが期待に引きずられるため）。

- カードを出していないのに「正色が出た」と記録されるなら、
  それはまぶたを通った光か、期待によるものです
- 出した色に応じて答えが変わるなら、見え方が本当に変わっていることになります

結果は分析タブの表で見られます。**この機能を切ると、記録が本物かどうかを確かめる手段がなくなります。**

設定タブでオフにできますが、おすすめしません。

## 脱力フェーズのランダム割り当て

脱力フェーズの有無を、アプリが**日ごとにランダムに決めます**。
自分で決めると、やる気のある日に脱力ありを選びがちで、比較になりません。

2〜3週間ためると、分析タブで「脱力あり」と「脱力なし」の正色出現率を比べられます。
これは、あなた自身を対象にしたランダム化比較試験です。

毎回かならず脱力したい場合は、設定タブでオフにできます（比較はできなくなります）。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（これ1つで動きます） |
| `manifest.json` | ホーム画面に追加するための設定 |
| `sw.js` | オフラインで開くためのキャッシュ |
| `icon-192.png` / `icon-512.png` | アイコン |

**5つとも同じ階層に置いてください。**

`index.html` をパソコンで直接開く（`file://`）と、Googleログインもオフライン機能も動きません。
どこかに https で公開してください（GitHub Pages / Netlify / Cloudflare Pages など）。

## 同期の設定（初回だけ）

1. Google Cloud Console でこのアプリの OAuth クライアントを開く
2. **承認済みの JavaScript 生成元**に、公開したURLを追加する
3. OAuth 同意画面のスコープに `https://www.googleapis.com/auth/drive.appdata` を追加する
4. PC でアプリを開き、設定タブ →「Googleに接続」
5. スマホで同じURLを開き、同じ操作をする

記録は Drive の「アプリ専用データ領域」に入ります。マイドライブには表示されません。

## v15 からのデータ

**消していません。**「記録」タブの一番下に「旧指標」として残ります。
ただし、いまの指標とは測っているものが違うので、続きとしては読めません。

## iPhone を使う場合

**必ず共有ボタンから「ホーム画面に追加」してください。**
Safari は、ホーム画面に追加していないサイトの保存データを約7日で消すことがあります。

**iPhone では振動が使えないため、合図は音だけになります。**
マナースイッチをオンにしていると音も鳴らないので、練習前に一度確かめてください。

## 効果について

正直に書きます。

- **期待できること**：目を閉じて力を抜き、光を減らした状態では、心に浮かぶ映像は普段より鮮明になります。
  これは実験で確かめられています。丁寧に手順を踏んだ日は、雑にやった日よりはっきり見えるはずです
- **期待できないこと**：「続けたらイメージ力そのものが底上げされる」という証拠はありません。
  イメージ訓練を直接調べた研究で伸びたのは「自分のイメージの状態を正しく言い当てる力」だけでした

**このアプリは「イメージ力が上がる」とは言いません。**
この手順を踏んだ日と踏まなかった日で、あなたに何が起きるかを記録する道具です。

根拠の強さを3段階に分けた説明が「分析」タブにあります。

## 注意

医療機器ではありません。目に不快感があるときはすぐに中止してください。
