# Orange Card v15.2 — 残像トレーニング記録 ＋ 視覚イメージ訓練

七田式オレンジカードの残像トレーニングを記録・可視化するツールです。
スマホとPCの記録は Google Drive 経由で自動同期されます。

v15.2 から「イメージ」タブが増えました。8週間で区切って、
**心的イメージと残像を切り分ける**訓練を進行・記録します。
オレンジカードとはデータが別系統ですが、同期は同じ仕組みに相乗りします。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（これ1つで動きます） |
| `manifest.json` | ホーム画面に追加するための設定 |
| `sw.js` | オフラインで開くためのキャッシュ |
| `icon-192.png` / `icon-512.png` | アイコン |

**5つとも同じ階層に置いてください。** サブフォルダに分けると動きません。

## 置く場所

`index.html` をパソコンで直接開く（`file://`）と、Googleログインもオフライン機能も動きません。
どこかに https で公開する必要があります。GitHub Pages / Netlify / Cloudflare Pages のいずれかに
フォルダごとアップロードしてください。無料の範囲で足ります。

## 同期の設定（初回だけ）

1. Google Cloud Console でこのアプリの OAuth クライアントを開く
2. **承認済みの JavaScript 生成元** に、公開したURL（例 `https://xxxx.github.io`）を追加する
   - ここを自分のドメインだけに絞ってください。空のままだと誰でもこのクライアントIDを使えます
3. OAuth 同意画面のスコープに `https://www.googleapis.com/auth/drive.appdata` を追加する
   - 以前の `drive.file` はもう使いません
4. PC でアプリを開き、設定タブ →「Googleに接続」
5. スマホで同じURLを開き、同じ操作をする

記録は Drive の「アプリ専用データ領域」に入ります。マイドライブには表示されず、
このアプリ以外からは読めません。ファイルを選ぶ操作は不要です。

同期のタイミングは、アプリを開いたとき / 記録した直後 / 別のタブから戻ってきたときです。

### 以前のバージョンからデータを移す

旧版で Drive に保存したJSONを一度手元にダウンロードし、
設定タブの「読み込んで統合」から入れてください。上書きではなく統合なので、
両方の端末で同じ操作をして問題ありません。同じファイルを何度読み込んでも増えません。

### 記録を消すとき

設定タブの「全削除」は、消したことも同期で伝わります。
片方の端末で消せば、もう片方も次の同期で消えます。
消した記録を戻したいときは、書き出しておいたJSONを「読み込んで統合」から入れてください。

## iPhone を使う場合

**必ず共有ボタンから「ホーム画面に追加」してください。**
Safari は、ホーム画面に追加していないサイトの保存データを約7日で消すことがあります。
同期を設定してあれば全部は失われませんが、追加しておくほうが確実です。

## 計測を安定させるために

設定タブの「計測の設定」で調整できます。

- **計測中の時間表示** … 「数字とゲージ」「ゲージだけ」「表示しない」から選べます。既定は数字とゲージです。
  ゲージはカードのすぐ下に出るので、視線を中心から外さずに残りが分かります。
  目を閉じている間は画面が見えないため、凝視の終わりと計測の終わりは音と振動で知らせます。
  「アニメーションを減らす」をオンにしていてもゲージは動きます
- **合図の音と振動** … 合図が鳴る瞬間はBGMが自動で下がります。
  **iPhone では振動が使えないため音だけになります。**
  マナースイッチをオンにしていると音も鳴らないので、計測前に一度確かめてください
- **目と画面の距離** … 記録に残ります
- **カードの見かけの大きさをそろえる（任意）** … 青いバーの幅をクレジットカードの辺に
  合わせて保存すると、視距離から逆算して視角が常に10°になる大きさでカードを描きます。
  スマホとPCの両方で設定すると、同期したデータを1本の線として読めます。
  合わせる辺は長辺（85.6mm）と短辺（53.98mm）から選べます。
  **スマホでは短辺のほうが画面に収まりやすく、合わせやすいです。**
  バーが画面をはみ出すときは、バーの上を横にスクロールすると続きが見えます

設定しなくても動きます。カードの形（横長4:3）と青い円の比率は較正の有無で変わりませんが、
実際の大きさは端末ごとに変わるため、分析タブの「測定条件」に警告が出ます。

## 集中用サウンド

設定タブから3種類選べます。

- **ピンクノイズ**（既定）… 拍がないので、残像の長さを測るときの時間の手がかりになりません。イヤホン不要
- **振幅変調トーン** … 音量を一定の速さで上下させます。脳波側の反応はこの形式がいちばん強く出ると報告されています。イヤホン不要
- **バイノーラルビート** … 左右で違う高さの音を鳴らします。ヘッドホン必須で、小音量では感じ取れません

いずれも効果が確立したものではありません。計測中はピンクノイズか無音をおすすめします。

## 使い方

1. 凝視時間と繰り返し回数を選んで「開始」
2. 青い円の中心を見つめる
3. 合図が鳴ったら**目を閉じる**
4. まぶたの裏の残像がぼやけ始めたら画面をタップ
5. 完全に消えたらもう一度タップ（「残存の計測をとばす」でも可。とばした記録は表で「—」と出ます）
6. 鮮明度と色を選んで記録

繰り返しを2回以上にすると、休憩をはさんで自動で次が始まります。
途中でやめるときは画面右上の「✕ 中止」か Esc キーです。

## イメージ訓練（8週間）

オレンジカードが「残像の持続」を測るのに対して、こちらは**残像を除いたうえで
随意的な心的イメージを測る**訓練です。同じ現象を逆向きに扱っています。

### なぜ切り分けるのか

何かが「見えた」とき、それが心的イメージではなく**残像**（目に焼き付いた像）で
あることがあります。ここを分けないと、何を鍛えているのか分かりません。
判定はアプリが毎回聞きます。

- 視線を左右に動かして**像が一緒に動いた** → 残像
- **像を空間に留められた／自分で動かせた** → 心的イメージ

### 4つのメニュー

| 段階 | 内容 |
|---|---|
| 1 図形 | アプリがランダムな図形を出して自動で隠します。教材の準備は不要です |
| 2 部分連鎖 | 手元の対象の一部分に注目 → 目をそらして保持。対象はご自分で用意してください |
| 3 全体像 | 複数の部分を見てから、全体像を思い浮かべます |
| 4 文字のみ | 内蔵の単語60語から1つ出ます。画像を見ずに思い浮かべます |

### 元の方法から変えたところ

ネット上で知られる Apps4Life 法は「0.25秒チラ見して、すぐ思い浮かべる」ですが、
それだと残像を見ている可能性が高いので、**目をそらして待つ時間**を挟みます。
既定は5秒で、3秒／5秒／10秒から選べます。
図形のコントラストも高・中・低から選べます。低いほど残像が出にくくなります。

判定が「残像」に偏るときは、コントラストを下げて待ち時間を伸ばしてください。
アプリ側からも同じ提案が出ます。

### 8週間で区切ります

56日経つと判定を促します。**平均鮮明度と「イメージ」判定の回数が動いていなければ、
そこで終了**です。延長はしないでください。これは意志や才能の問題ではありません。
先天性アファンタジアに対して再現性のある訓練法は、現時点で確立されていません。

### 2つを並べて見る

イメージタブのいちばん下に「2つの訓練を並べて見る」があります。
イメージ訓練の開始日を1日目として、**残像の持続（秒）**と**イメージの鮮明度（0〜5）**を
同じ週の目盛りに並べます。単位が違うので上下2段に分けてあります
（1本の軸に重ねると、伸び方を実際より揃って見せてしまいます）。

図の下に「同じ向きに動いたのが何回、逆向きが何回」と出ますが、
**これは転移の証拠にはなりません。** 週が数個ある程度では偶然どちらにも転びますし、
同じ時期に両方やっていれば体調や生活の変化で一緒に動くこともあります。
気になる動きがあるかどうかを眺めるための図として使ってください。
残像の持続を伸ばすと随意的なイメージも伸びるのかは、
査読を経た研究で確かめられたものがありません。

### 記録の書き出し

設定タブのバックアップのカードに、ボタン列が2つあります。
上がオレンジカードの記録、下がイメージ訓練の記録です。
**どちらの「全削除」も、もう一方には影響しません。**

イメージ訓練側は JSON（書き出し・読み込んで統合）と CSV が使えます。
読み込みは上書きではなく統合で、同じファイルを何度読み込んでも増えません。
全削除のあとに読み込むと、記録だけでなく開始日やベースラインも戻ります。
Drive の同期ファイルをそのまま読ませても通ります。

## 注意

医療機器ではありません。目に不快感があるときはすぐに中止してください。
このトレーニングの効果について、査読を経た研究で確認されたものはありません。
記録ツールとしてお使いください。

## v15.2 で足したこと

- 「イメージ」タブを追加（8週間の視覚イメージ訓練）。図形の生成・待ち時間の計測・
  残像チェックの誘導・記録・グラフまでアプリ側で進行します
- 「2つの訓練を並べて見る」を追加。残像の持続とイメージの鮮明度を同じ週軸に並べます
- イメージ訓練の記録に、JSONの書き出し／読み込んで統合／イメージ側だけの全削除を用意しました
- イメージ訓練のグラフは Chart.js を使わないため、CDNが読めない環境でも表示されます
- 同期ファイルにイメージ訓練の記録が相乗りします（`schema: 4`）。
  **v15.1 以前を同じアカウントで開くと、イメージ訓練の記録が同期で消えます。**
  両方の端末を v15.2 に上げてください
- タブが5つになったので、狭い画面ではヘッダーが折り返さず横スクロールになります

## v15.1 で直したこと

- グラフ用のファイル（Chart.js）を読み込めないとき、設定・同期・Escが配線されず、
  さらに1回記録すると開始ボタンが押せなくなっていたのを修正。
  グラフが出せないときも記録と同期はそのまま使えます
- 同期が同時に走ると、Drive内に保存ファイルが複数できて記録が分裂することがあったのを修正
- 較正していない記録の「視角」が 0.1° として保存され、測定条件の警告が出なくなっていたのを修正。
  カードの幅（mm）も保存されるようになりました
- idを持たない古いバックアップを読み込むと、読むたびに記録が増えていたのを修正
- 「全削除」が同期で元に戻ってしまうのを修正（消したことも同期されます）
- スマホで較正バーがクレジットカードの幅まで伸びず、実寸合わせができなかったのを修正
- 較正していないときのカードが縦長になり、青い円の比率も較正時と違っていたのを修正
- 「アニメーションを減らす」設定でゲージが動かなくなっていたのを修正
- 分析タブの「あなた」バッジが2回目以降つかなくなっていたのを修正
- 休憩中に Esc と ✕中止 が効かなかったのを修正
- 計測終了と同時にEscを押すと、中止したのに記録画面が出ることがあったのを修正
- 「残存の計測をとばす」を鮮明時間のコピーとして保存していたのを、未測定として保存するよう変更
- ページを離れて戻ったあと、音が無言で鳴らなくなることがあったのを修正
- 凝視時間の終わりを表示用のタイマーと切り離し、設定した秒数で正確に終わるようにしました
